VERIFICATION — VERSION 4.5.0
============================
108 automated tests pass (52 backend, 56 frontend) using in-memory SQLite,
simulated Firebase/Classroom responses, and execution of the actual frontend
script in a DOM test harness. No real Google Classroom assignment was created
or modified by these tests.

New in 4.5.0: feedback scores/comments/revision and student view; progress for
Present mode (owner only); data export; account deletion cascading through
postings, submissions, groups, shares and workspace. End-to-end: a teacher
posts, two students submit, the teacher grades both with the rubric queue and
comment bank, returns one for revision, downloads the CSV, opens insights and
Present mode (spotlight, pause/resume, Esc), the student sees the revision
request on a phone, downloads their data and deletes their account.

New in 4.4.0: 20 simulated sessions (10 teacher, 10 student; new-to-tech and
power-user teachers; middle- and high-school students, struggling and
advanced) against the real Worker on a Chromebook (1366x768), 1440 and 1920
desktops, iPad portrait (820) and landscape (1024) and a phone (390), in light,
dark and high-contrast themes. Every screen was checked for sideways
scrolling, text under 12px, low contrast, small tap targets, stray text and
errors. First run: 74 accessibility, 4 layout and 3 flow findings plus 5
blocked sessions. Final run: all 20 complete; only hexagon labels that shrink
to fit long words (about 11px) remain.
Fixed: connection reasons squeezed one word per line (homepage .why style
collision); sign-up form erased the typed name after an error; long titles
overflowed the page; low-contrast teal and red labels; 30px tap targets on
touch screens; the editor pushed far down by the Hex Space list on tablets;
the open Hex Space's folder collapsed; an unneeded name box on the student
board; raw status words ("new", "draft"); a "Grade and return in Classroom"
button on code-only classes; submissions page back link, wording and group
text; class page layout; student dashboard layout.

New in 4.3.0: posting one Hex Space to several classes at once; posting from a
class page with a Hex Space picker, repeatedly; new folders from the folder
drop-down (including inside another folder); deleting a Hex Space with its
open postings closed; offering to update open postings after an edit.

New in 4.2.0: whole-day dates in the teacher's time zone across daylight saving;
posting the same Hex Space to a class repeatedly with distinct codes; students
blocked before the start date; late flag from the due date; editing, closing,
reopening and refreshing a posting; Classroom scheduled drafts and due dates;
refused Classroom postings leave nothing pending; migration 0005 tested with
existing submissions and group boards.

New in 4.1.0: email + password accounts (verified only), locked account types,
teacher-only routes refusing students, Classroom requiring a linked Google
account, closing removed code-only classes, the login and sign-up pages, the
confirm-your-email step, menus for each role, clean page addresses, choosing
which Classroom classes to import, resync, and removing classes.

An end-to-end run used the real Worker and all migrations on SQLite with
Google sign-in and Classroom simulated: homepage, Log in, Google sign-up as a
teacher, choosing classes to import, resync, adding and removing classes,
building and posting a Hex Space, sharing, Shared links, Sign out, resuming a
private page after login, a student creating an email account from a class
code, confirming the email and joining, a student blocked from teacher pages,
and an old # Classroom link forwarding. No API errors or page problems.

New in 4.0.0: folder-tree validation (depth, cycles, missing parents); code-only
class posting, joining, turn-in, reclaim and grading without Classroom; closed
and unknown codes, reposting and code clashes; group codes in code-only classes;
the share lifecycle (create, preview, copy count, update, revoke, non-teacher
blocking); the homepage; the pending code flow through sign-in; New Hex Space
hidden from students; folder create/move/delete; Classroom class import;
share preview and copy; students blocked from share pages; imported Classroom
classes saved to the Hex Space and listed under Your classes without
reconnecting Classroom; the homepage as the starting page with Log in.

Earlier coverage remains: Google signup/profile persistence; account/workspace
isolation; Classroom permissions, course discovery and assignment membership;
publishing, republishing, grading, reclaim and immutable submitted snapshots;
AI validation and quotas; board validation and expanded layouts; dashboards;
group ownership, capacity, joining, leaving, merges and conflicts.

Browser QA (Playwright Chromium, stubbed Firebase and API) covered the homepage,
mobile menu, code entry, editor with nested folders and drag-and-drop, folder
menu, share dialog, Classes & codes with a code-only class, the posted-code
dialog, account menu, dashboard, share preview and the student view, at 1280px
light and 390px dark. No layout or console problems were found.

Not verified here: live Google OAuth, real Classroom publishing/grading, and
D1 migration 0004 on the production database.
