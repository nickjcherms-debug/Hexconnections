WORKSPACE CONFLICTS
Saving a workspace uses a revision check so one tab cannot silently overwrite
another device. On a conflict, download a workspace backup, then reload. A local
backup displaced by a newer server revision is preserved in browser storage and
is available through Download workspace backup. Reapply edits intentionally.

INTERRUPTED PUBLICATION
A newly published assignment first gets a posts row with status CREATING.
If Google or the network fails after creation, the app refuses automatic retries.
Check the target Classroom course for the new assignment:
- If it exists, identify its courseWork ID using the Classroom API and update the
  row with that coursework_id, classroom_url and status PUBLISHED.
- If you verify that no Classroom assignment was created, delete only that
  unresolved CREATING row and retry publication.
Do not delete PUBLISHED rows or other teachers' data when reconciling a failure.
