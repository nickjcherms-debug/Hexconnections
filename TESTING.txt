VERIFICATION — VERSION 4.10.0
============================
108 automated tests pass (52 backend, 56 frontend) using in-memory SQLite,
simulated Firebase/Classroom responses, and execution of the actual frontend
script in a DOM test harness. No real Google Classroom assignment was created
or modified by these tests.

New in 4.10.0: 131 tests. One connected board: default on for new postings,
turn-in refused with code flow-broken when explained connections leave separate
groups, a D&C hexagon bridges terms, switched off per posting, older postings
and edits of their other switches unaffected; client grouping ignores empty
reasons and non-touching pairs; Submit message names the unlinked terms.
Chromium: Setup and Post dialog default on; a two-group board shows the count,
red outlines and the turn-in message.
New in 4.9.0: 129 tests. Three-way merge (folders, moves, edits, deletes; open
editor object kept), merging an earlier visit's unsaved folders on login, the
directory (top level, inside a folder, search by term), paste blocking and the
grader count; backend paste option defaults/overrides and attempt count.
Chromium: folder auto-saved; Hex Space created inside a folder; second device
sees it; two devices adding folders at the same time keep all four; focus pulls
changes; sign-out/in keeps folders; search; phone layout; posting defaults to
block pasting; a synthetic paste is blocked with the note shown.
New in 4.8.0: Assign to class menu and Ready-to-assign bar (unit test plus Chromium run:
new Hex Space → Assign to class → Period 4 preselected → posted → bar disappears). 124 tests.
New in 4.7.0: 123 automated tests. Backend: versions (trimmed boards, teacher-only
moves, version names hidden), student supports (definitions stripped server-side,
later changes), gallery (anonymous boards, turn-in required, own-board comments
refused, teacher authors/hide, deletion cascade), library (search by terms and

dialog, starters, history recording and replay states, reflection, print page
escaping, grader extras, gallery naming, Microsoft button. End-to-end in Chromium
against the real Worker: print page, posting with definitions off and two
versions, translation, starters, reflection, versions panel, gallery open and
comment, grader reflection and replay, library publish/search, site stats.
New in 4.6.1: AI-suggested scores (4.6) removed for now; vocabulary generation unchanged.
New in 4.5.0: feedback scores/comments/revision and student view; progress for
Present mode (owner only); data export; account deletion cascading through
postings, submissions, groups, shares and workspace. End-to-end: a teacher
posts, two students submit, the teacher grades both with the rubric queue and
comment bank, returns one for revision, downloads the CSV, opens insights and
Present mode (spotlight, pause/resume, Esc), the student sees the revision
request on a phone, downloads their data and deletes their account.

New in 4.4.0: 20 simulated sessions (10 teacher, 10 student; new-to-tech and
power-user teachers; middle- and high-school students, struggling and
advanced) against the real Worker on a Chromebook (1366x768), 1440 and 1920
desktops, iPad portrait (820) and landscape (1024) and a phone (390), in light,
dark and high-contrast themes. Every screen was checked for sideways
scrolling, text under 12px, low contrast, small tap targets, stray text and
errors. First run: 74 accessibility, 4 layout and 3 flow findings plus 5
blocked sessions. Final run: all 20 complete; only hexagon labels that shrink
to fit long words (about 11px) remain.
Fixed: connection reasons squeezed one word per line (homepage .why style
collision); sign-up form erased the typed name after an error; long titles
overflowed the page; low-contrast teal and red labels; 30px tap targets on
touch screens; the editor pushed far down by the Hex Space list on tablets;
the open Hex Space's folder collapsed; an unneeded name box on the student
board; raw status words ("new", "draft"); a "Grade and return in Classroom"
button on code-only classes; submissions page back link, wording and group
text; class page layout; student dashboard layout.
