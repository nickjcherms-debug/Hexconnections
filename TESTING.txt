VERIFICATION — VERSION 3.0.0
============================
58 automated tests pass using in-memory SQLite, simulated Firebase/Classroom
responses, and execution of the actual frontend script in a DOM test harness.
No real Google Classroom assignment was created or modified by these tests.

Coverage includes Google signup/profile persistence; account/workspace isolation;
Classroom permissions, course discovery and assignment membership; publishing,
republishing, grading, reclaim and immutable submitted snapshots; AI validation
and quotas; board validation and expanded layouts; teacher dashboard routing,
course/assignment counts and student active/submitted lists; assignment/group
code entry; group ownership, capacity, idempotent joining, leaving, one-group-per-
assignment constraints, unauthorized access, independent-edit merges, conflicts,
placement collisions and authoritative group revisions at turn-in. Missing group
tables produce setup guidance while individual boards continue to work.

Run with Node 24:
  npm test
Wrangler build check (after npm install):
  npx wrangler deploy --dry-run
Read-only deployment routing check:
  npm run check:deployment

The current source is based on GitHub main ea8e371 and includes the pending
signup/debug fixes. Build/routing checks do not verify Google OAuth, live school
policies, real Classroom publishing/turn-in/grading, real model inference, or D1
production migrations. Those require an authenticated deployment and test users.

Browser QA used preview-only synthetic teacher/student accounts and API responses.
Verified classroom cards, assignment lists, submissions, group controls and the
student assignment/code sections. A missing-action rendering issue was found,
fixed and covered by a regression test. Fixtures are excluded from the source.
Wrangler 4.156.0 successfully bundled the Worker with DB, AI and ASSETS bindings.
